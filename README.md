# MakoPulse Agent for macOS: releases

Signed (Developer ID, Mako Logics LLC, team 462TTZGQNM) and Apple-notarized installer packages for the MakoPulse RMM agent. Installers only; no source.

Each release has `MakoPulseAgent-X.Y.Z.pkg` and `mac.json` (version, SHA-256, signed, notarized). The agent and `install/mac.sh` refuse any package whose fingerprint, Mako Logics signature or notarization does not check out.
